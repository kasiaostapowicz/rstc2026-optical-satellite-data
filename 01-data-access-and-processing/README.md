## Part 1: Optical Satellite Data: Access and Processing

This module introduces practical access to Sentinel-2 Level-2A data and basic processing steps for optical satellite observations. The exercise covers data search and selection, image preview, quality and cloud screening, spectral bands, and the calculation and visualisation of NDVI using Python in Google Colab.
